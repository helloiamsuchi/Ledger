# Ledger — Expense Tracker

## Live Demo
[View Live →](https://helloiamsuchi.github.io/Ledger/)

## Features

- Add & delete income/expense transactions
- Spending breakdown by category (donut chart)
- 6-month income vs expense bar chart
- Budget limits with progress bars (turns red when over)
- Monthly summary — total income, expenses & savings rate
- Data persists via localStorage

## Tech Stack

HTML · CSS · JavaScript (Canvas API for charts)
